# Security policy

Please report vulnerabilities **privately**, not in a public issue: write to
[pietzsch@michaelpietzsch.de](mailto:pietzsch@michaelpietzsch.de) with a description, the affected version or commit,
and how to reproduce it. You will get an answer within a week. Please give a fix the time it needs before you talk
about the issue publicly; you will be credited unless you prefer not to be.

In scope: the server, the specification (`spec/`) and the container image of this repository. How Vinyl-Mind is
secured, and its known limits, are described in [docs/security.md](docs/security.md).
